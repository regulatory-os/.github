## 💡 Notre mission

Démocratiser l'accès aux outils de conformité réglementaire grâce à l'**open source** et à l'**intelligence artificielle**.

> *"La conformité est un métier de jugement. L'IA ne remplace pas les experts, elle les augmente."*

## 🚀 Nos outils open source

### 📋 ICT-Contractuel-Checks

**Audit automatisé des contrats d'externalisation ICT par IA**

| | |
|---|---|
| 🎯 **42 critères** | DORA Art. 30, EBA Guidelines, Arrêté français 2014 |
| 🤖 **IA multi-modèles** | Claude Opus · Gemini · GPT-4 |
| 📊 **Scoring** | Note de conformité 0-100% avec recommandations |
| 📄 **Export** | Rapports PDF et Excel professionnels |

➡️ **[Code source](https://github.com/regulatory-os/ICT-contractuel-checks)** · **[Démo en ligne](https://regulatory-os.com/tools/ict-check)**

---

### 🌍 African-Screening

**Screening contre les listes de sanctions africaines (UEMOA/CEMAC)**

| | |
|---|---|
| 🗺️ **4 pays** | Côte d'Ivoire · Burkina Faso · Mali · Niger |
| 👥 **216+ entrées** | Personnes physiques et morales |
| 🔍 **Fuzzy matching** | Algorithme Levenshtein avec seuil ajustable |
| 📄 **Export** | Rapports PDF conformes aux exigences LCB-FT |

➡️ **[Code source](https://github.com/regulatory-os/African-screening)** · **[Démo en ligne](https://regulatory-os.com/tools/africa-sanctions)**
